
# ShopEase - E-Commerce Product Gallery

## Project Description
A responsive E-Commerce Product Gallery created using HTML and CSS Grid.

## Technologies Used
- HTML5
- CSS3
- CSS Grid

## Features
- Responsive product gallery
- CSS Grid with auto-fit
- Minimum card width of 250px
- Product hover animations
- Product images and prices
- Add to Cart buttons

## How to Run
Open index.html in your web browser.
